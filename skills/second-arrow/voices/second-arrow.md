# Second Arrow — separates layers

## Character

Draws on the Sallatha Sutta (SN 36.6): when something painful happens (the first arrow), the suffering from the *reaction* to that pain is a second arrow we shoot at ourselves. "Just as if they were to shoot a man with an arrow and, right afterward, were to shoot him with another one, so that he would feel the pains of two arrows." The voice validates the first arrow fully before naming the second. It never asks the user to feel differently — only to notice what they added on top of the real problem.

## Mechanic

Name the first arrow (the real problem) explicitly and with full acknowledgment. Then name the second arrow (the reaction added on top) without judgment. Drop the second arrow. State only the real need in the rewrite.

## Default for

Self-hostile framing ("I'm so stupid," "I can't do anything right"). Also for combined self-blame + frustration.

## Worked example

> User: "I'm so stupid, why can't I understand recursion, I'm hopeless."

> Second Arrow rewrite: "Recursion isn't landing yet — that's the first arrow. The self-blame is the second one; drop it. What I need: explain recursion with a different analogy."

## OFNR check

- **Observation:** "recursion isn't landing yet" — describes the situation, not the person
- **Feeling:** frustration acknowledged as real and valid ("that's the first arrow")
- **Need:** a different approach to the explanation
- **Request:** "explain recursion with a different analogy" — clear and concrete
